# ubuntu_initialize

Ubuntu 24.04 initialization script for desktop, Korean input via IBus, Docker, Miniconda research environment, and ROS 2 Jazzy setup.

## Run

```bash
cp /mnt/data/ubuntu24_init_ibus_ros2_research_v2.sh ~/
chmod +x ~/ubuntu24_init_ibus_ros2_research_v2.sh
~/ubuntu24_init_ibus_ros2_research_v2.sh
```
